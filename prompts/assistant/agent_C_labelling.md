# Agent C: labelling setup, guidelines, agreement tooling, Google Form

Follow `prompts/assistant/agent_common_rules.md`.

Context: humans (two annotators, IDs A1 and A2) audit LLM-paraphrased queries and justifications in Label Studio. Each item shows: the student summary, the template query, the paraphrased query, the rule-engine gold answer, the paraphrased justification. Label levels in this fixed order: 1) decision accept/edit/reject, 2) error category, 3) edit text (required when decision = edit). Categories are in docs/DATA_CONTRACT.md. Round 1 uses guidelines v1 (40 overlapping items), round 2 uses v2 (40 new overlapping items). Item order is shuffled with `seeds.annotation_order`. Annotators do not see each other's labels or any model prediction of the label.

Build:
1. `labelstudio/config_v1.xml` (and later v2 if the label set changes; for now copy as config_v2.xml only if needed) using Choices for decision and category and a TextArea for edit, laid out top to bottom in the fixed order. Install Label Studio in a SEPARATE venv `.venv-labelstudio` (add it to .gitignore), record its exact version, and verify the config parses (for example with `label_studio.core.label_config.parse_config` or by starting a project via the SDK/CLI if simple). If install fails due to disk or time, say so and still produce a config that follows the documented tag syntax.
2. `src/queries/to_labelstudio.py`: from `data/processed/queries.jsonl` (with para fields filled), sample the round-1 and round-2 item sets (stratified by intent, disjoint between rounds, seeded), write `data/labels/round{1,2}/tasks.json` in Label Studio import format and `data/labels/round{1,2}/manifest.csv` (item order, item ids, annotators). Works on a fixture if queries.jsonl is not ready.
3. `src/queries/agreement.py`: read raw Label Studio JSON exports placed at `data/labels/round{N}/export_A1.json` and `export_A2.json` (never modify them), compute Cohen's kappa for decision and for error category, raw percent agreement, confusion matrices (CSV + PNG), and a disagreement table with both labels and edits for every disagreeing item. Output under `supporting_files/C_labelling/round{N}/`. Test it with a synthetic export fixture in `tests/fixtures/` that is clearly named as a fixture; never write anything to data/labels.
4. `src/queries/adjudicate.py`: merge the two exports with an adjudication CSV (`data/labels/round{N}/adjudication.csv`, filled by a human: item_id, final_decision, final_category, final_edit, decided_by) into `data/labels/audited.jsonl`.
5. `labelstudio/guidelines_v1.md`: 1 to 2 pages: task purpose, definitions of each decision and category, the label order rule and why, edge cases (partially correct justification, correct but awkward paraphrase, paraphrase that changes the target course, abbreviations, missing semester info), and 4 to 6 worked examples. Leave `guidelines_v2.md` as a copy with a header "to be revised after round 1".
6. `LABELLING_PROTOCOL.md` skeleton with all sections the assignment requires (who labelled what, tools and versions, config per round, guideline version per round, order of label levels and rationale, order of items and seed, what annotators could see, disagreement resolution and who decided, timeline matched to export files), with TODO markers only where human facts are needed (dates, annotator assignments).
7. `docs/GOOGLE_FORM.md`: the exact form to create: title, intro text, consent checkbox (anonymous, used for a course project dataset, no names/emails collected; turn off email collection), fields: programme (MTech-CSE / MTech-AI / other), stream, track, semester, courses completed (free text), the question they would ask an academic advisor (free text, required), what kind of question (remaining requirements / eligibility / elective advice / other). Plus `src/collect/import_forms.py` that reads the downloaded CSV at `data/raw/forms/responses_raw.csv`, drops any timestamp-to-identity linkage, assigns R001.. ids, writes `data/raw/forms/responses_anonymised.jsonl` and fills `data/consent_register.csv`. Test with a fixture only.

Report the Label Studio version, how to launch it for the two annotators (including how A2 can label remotely, e.g. export/import project or shared machine), and the files created.
